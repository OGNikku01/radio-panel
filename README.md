# Radio Panel — Live Radio Only

Colorful white-background radio dashboard for GitHub Pages. It contains live radio channels only: no music player, song library, or playlist.

## Features
- India and World live radio directory
- News & Talk, Devotional, Classical and Sports categories
- Search radio stations
- Play, pause, stop, previous/next and volume
- Favourites saved in the browser
- Responsive mobile layout

## Publish on GitHub Pages
1. Create a public repository named `radio-panel`.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/(root)`, and Save.
5. Wait for GitHub Pages to show your published URL.

## Notes
The directory is retrieved from the community Radio Browser API. Audio streams are hosted by individual broadcasters. Some streams may be offline or block browser playback; switch stations if one fails. Internet is required. GitHub Pages hosts the website independently of your phone.
